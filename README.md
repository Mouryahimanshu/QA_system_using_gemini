# QA System using Gemini

An AI-powered Question Answering system built using Google Gemini API and LangChain that generates intelligent, context-aware responses from custom documents and knowledge sources.

## Live Demo

🔗 [Try the Application](https://mouryahimanshu-qa-system-using-gemini-streamlitapp-1eswyz.streamlit.app/)

---

## Features

- AI-powered conversational Question Answering system
- Context-aware response generation using Gemini API
- Retrieval-Augmented Generation (RAG) pipeline
- Semantic search and intelligent document retrieval
- NLP-based preprocessing and embeddings
- Interactive Streamlit web interface
- Real-time conversational AI workflow

---

## Tech Stack

- Python
- Google Gemini API
- LangChain
- Streamlit
- NLP
- Vector Embeddings

---

## Project Workflow

1. Load and preprocess documents
2. Generate embeddings for semantic understanding
3. Store embeddings for efficient retrieval
4. Retrieve relevant context from user queries
5. Generate intelligent responses using Gemini LLM
6. Display answers through Streamlit interface

---

## Installation

Clone the repository:

```bash
git clone https://github.com/Mouryahimanshu/QA_system_using_gemini.git
cd QA_system_using_gemini
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## Environment Setup

Create a `.env` file in the root directory:

```env
GOOGLE_API_KEY=your_api_key_here
```

---

## Run the Project

```bash
streamlit run app.py
```
